## 🦖 Sitessauro  

Um site informativo dedicado ao mundo dos dinossauros, oferecendo curiosidades, fatos interessantes e detalhes sobre essas criaturas pré-históricas.  

## 🌐 Demonstração  
Acesse o site ao vivo em: [Sitessauro](https://andre-studionerd.github.io/Sitessauro/)  

## 🚀 Tecnologias  
- HTML5  
- CSS3  
- JavaScript  

## ✨ Funcionalidades  
- Informações sobre diversos dinossauros  
- Design intuitivo e responsivo  
- Seções que abordam características, extinção, e curiosidades dos dinossauros  

## 📥 Como rodar o projeto localmente  
1. Clone o repositório:  
    ```bash
    git clone https://github.com/Andre-StudioNerd/Sitessauro.git
    ```
2. Acesse o diretório do projeto:  
    ```bash
    cd Sitessauro
    ```
3. Abra o arquivo `index.html` no navegador para explorar o conteúdo sobre dinossauros!
